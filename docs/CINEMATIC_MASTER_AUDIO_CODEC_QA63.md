## Minimal correction

The opt-in strict inspector now requests audio `codec_name` and `profile` from FFprobe. If an optional single audio stream is present, strict integrity requires **AAC, LC profile**. Explicit non-AAC or non-LC evidence increments `audio_codec_anomaly_count`; missing codec/profile evidence increments `audio_codec_unattested_count` and fails strict attestation without claiming corruption. Video-only remains allowed. Legacy decode-only exit behavior remains unchanged. The report contains only aggregate counts and no owner paths, asset IDs, media bytes, prompts or stored SHA values. No media deletion or modification.

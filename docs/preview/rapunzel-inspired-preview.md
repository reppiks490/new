# Rapunzel-inspired custom build preview

This preview uses the current Forma Studio browser build and its licensed adult base mesh. The intended preset is:

- long hair asset: `long01`
- green iris and warm light skin palette
- purple bikini collection with mature fashion enabled
- no exact Tangled/Rapunzel movie asset is included in this repository

The build is therefore a Rapunzel-inspired original character. An exact movie character requires a licensed asset supplied by the user.

The interactive preview is available from the repo root with:

```bash
./.venv/bin/uvicorn app.studio.server:app --host 127.0.0.1 --port 8766
```
